# Simulator provenance

The lesson specifications and simulation engines in this directory were ported from:

- Repository: `https://github.com/dylanjayabahu/ibm-ai-engineering`
- Local source at integration time: `simulator/src/engines` and `simulator/src/lessons`
- Latest readable commit in the local source repository at integration time: `a27c2ee82de6a958d11b35b25b391f504f8915ac` (the working-tree index could not be inspected reliably).

The host-specific dialog, Firebase progress bridge, exact-path manifest, and scoped styles were added for AI Engineering Guide. The simulator's app shell, theme controls, translation adapter, local-storage progress store, launcher, and `/source` server route were not copied.

No standalone `LICENSE`, `COPYING`, or `NOTICE` file was present in the source tree at integration time. Confirm repository ownership or permission before redistributing these files outside this project. Course materials remain subject to their original terms and should not be copied into graded submissions.
